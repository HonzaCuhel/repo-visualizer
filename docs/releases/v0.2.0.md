Repo Visualizer 0.2 makes the source explorer smaller, clearer and multilingual.

- Compact type and controls, a clear installation CTA, and restrained content reveals while scrolling.
- Light, dark and system appearance across the website, portable explorer and rendered exports.
- English/Czech site and interface. Explanation language follows the user's request independently of the coding agent; other interface languages can provide a translated dictionary.
- Standalone pages have short leads, optional source-linked orientation, separate counts/duration/revision metadata and expandable detail.
- Fixed nested-group edge coordinates, preventing unrelated edges from appearing over the wrong components.
- Refined English and Czech README files with real, theme-aware animation previews.
