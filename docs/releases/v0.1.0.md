Repo Visualizer turns a repository question into a source-grounded component graph you can explore and share.

- Open skill for Codex and Claude Code.
- Nonlinear graphs with branches, cycles, parallel relationships and groups.
- Map, Focus and Path views, embedded source excerpts and pinned code links.
- Portable offline HTML; PNG, SVG, GIF, MP4 and WebM exports from one scene.
- Optional HyperFrames adapter; no account or hosted gallery required.

Try the [live interactive example](https://honzacuhel.github.io/repo-visualizer/).

```sh
npx skills add HonzaCuhel/repo-visualizer@v0.1.0 --skill repo-visualizer -a codex -a claude-code
```

Run inside your repository; add `-g` for a personal installation. Installer: Node.js 22.20+. Core build: Python 3.9+. Animated exports require optional browser/rendering dependencies.

Fresh Codex and Claude Code sessions independently generated graphs, offline HTML and GIFs from public source. Codex on macOS needed approval for the trusted browser export command outside its sandbox. See [verification and limitations](https://github.com/HonzaCuhel/repo-visualizer/blob/v0.1.0/docs/verification.md), including the disclosed Impeccable workflow-ledger exception.

The agent authors the explanation; matching source fingerprints does not prove semantic correctness. Static source walkthroughs are not runtime traces. Generated HTML contains source excerpts: keep private-repository outputs private.

The ZIP contains the complete skill. SHA256SUMS.txt verifies the ZIP; explorer.html, walkthrough.gif and walkthrough.mp4 are attributed public-source examples. Original code MIT; vendored assets retain their licenses.
