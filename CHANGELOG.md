# Changelog

## 0.2.0 — 2026-11-07

- Compact typography and controls, with a clear installation action and restrained scroll reveals.
- Light, dark and system appearance in the site and portable explorer; themed SVG, PNG and animation exports.
- English/Czech site and interface, display-only graph translations, and agent-independent output language with custom interface dictionaries.
- Refined English README and a complete Czech README, with theme-aware real animation previews.
- Correct nested ELK edge coordinates: edges returned at the root now use their declared container, preventing unrelated paths crossing components.
- Updated local repository examples and regression coverage for source-preserving language switches, offline downloads and nested edge attachment.

## 0.1.0 — 2026-11-07

First public release of Repo Visualizer, an open skill for Codex and Claude Code.

- Source-grounded component graphs with typed relationships, groups, branches, cycles and parallel edges.
- Map, Focus and Path views with source inspection, pinned links and optional walkthroughs.
- Portable offline HTML and PNG, SVG, GIF, MP4 and WebM exports from one scene.
- Optional HyperFrames adapter for local video rendering.
- Static public demo, downloadable examples and project/personal installation through the skills CLI.
- Fresh independent coding-agent tests and automated renderer/source validation.
